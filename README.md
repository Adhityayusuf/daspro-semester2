# Algoritma dan Struktur Data — Semester 2

Kumpulan kode praktikum **Algoritma dan Struktur Data (ALSD)**
menggunakan Java, diorganisir per pertemuan. Tiap pertemuan berisi
program latihan, tugas, laporan, dan screenshot output.

## Materi per Pertemuan

| Pertemuan | Topik |
|-----------|-------|
| 1 | Pemilihan, perulangan, array, dan fungsi dasar |
| 2, 3, 5–7 | Lanjutan materi dasar + tugas |
| 10 | **Stack** — konversi bilangan, surat antrian, `StackTugasMahasiswa` |
| 11 | **Queue** — antrian KRS dan layanan akademik SIAKAD |
| 12, 13, 15, 16 | Materi lanjutan struktur data |

Laporan jawaban praktikum ada di tiap folder (`laporan/report.md`
atau `Laporan/LaporanN.md`), begitu pula screenshot output di folder
`gambar/`.

## Cara Menjalankan

```bash
cd "pertemuan 10"
javac StackKonversi13.java
java StackKonversi13
```
